# Ivorian Supermarket Landing Page

![image](https://github.com/user-attachments/assets/70de238c-c098-48d3-8699-39e0bfd997b8)

## Overview
This project is a **responsive landing page** for an online supermarket showcasing products from **Ivory Coast (Côte d'Ivoire)**. The page includes a header, a hero section, a product section, and a footer. It is designed to be visually appealing and fully responsive, ensuring a seamless experience on both desktop and mobile devices.

## Features
- **Header**: Includes a logo and a navigation menu with links to different sections of the page.
- **Hero Section**: A visually appealing banner with a call-to-action button.
- **Product Section**: Displays four Ivorian products (cocoa, coffee, palm oil, and cashew nuts) in a responsive grid.
- **Footer**: Contains copyright information and links to privacy policy and terms of service.
- **Responsive Design**: The layout adjusts seamlessly for various screen sizes using **CSS Grid** and **media queries**.
- **Custom Styling**: Uses **Tailwind CSS** for utility classes and custom CSS for finer control.

## Technologies Used
- **HTML5**: For structuring the page.
- **CSS3**: For styling and responsiveness.
- **Tailwind CSS**: For utility classes and enhanced responsiveness.
- **Google Fonts**: For the "Poppins" font.
